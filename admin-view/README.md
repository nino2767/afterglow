# AFTERGLOW — Admin Console

> AI 기반 스핀오프 팝업 통합 운영 솔루션 · 어드민 UI 프로토타입

## 화면 구성

### 운영자 어드민 (B2B 기획사용)
| # | 화면 | 설명 |
|---|------|------|
| 01 | 대시보드 | 프로젝트 현황 + MVP 진행률 |
| 02 | IP 업로드 | 전시 자산 업로드 + AI 분석 실행 |
| 03 | Concept Bot | 스핀오프 컨셉 3종 선택 + 운영 가이드 생성 |
| 04 | 관람 모니터 | 실시간 관람 데이터 + 키워드 클라우드 |
| 05 | 성과 리포트 | 전환 퍼널 + RS 현황 + AI 액션 추천 |
| 06 | 정산 관리 | RS 배분 계산 + 지급 승인 |

### 슈퍼 어드민 (AFTERGLOW 내부용)
| # | 화면 | 설명 |
|---|------|------|
| 07 | 고객사 관리 | 파트너 기획사 등록 + 플랜/RS 관리 |

## 반응형 지원
- **데스크톱** (`> 1024px`): 풀 사이드바 + 멀티 컬럼
- **태블릿** (`768~1024px`): 아이콘 사이드바 + 조정된 그리드
- **모바일** (`< 768px`): 하단 탭바 + 바텀 시트 + 단일 컬럼

## 로컬 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 후 상단 스위처로 페이지 이동

## 기술 스택
- React 18
- Vite 5
- lucide-react (아이콘)
- 순수 인라인 스타일 (CSS-in-JS)
