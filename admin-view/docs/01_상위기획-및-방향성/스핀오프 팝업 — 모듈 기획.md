# 스핀오프 팝업 — 모듈 기획

> v1.1 — 2026.06.09 | 공동 작업자 안(경험 모듈) + 기존 안(공간 테마 모드) 통합

---

## 두 안의 관점과 레이어

두 안은 충돌하지 않습니다. **레이어가 다릅니다.**

|  | 공간 테마 모드 (기존 안) | 관람객 경험 모듈 (공동 작업자 안) |
| --- | --- | --- |
| **설계 관점** | 팝업 공간 컨셉·테마 중심 | 관람객 경험 행동 중심 |
| **분류 기준** | 어떤 세계를 만드는가 | 무엇을 하게 하는가 |
| **주 활용처** | B2B 기획사 Concept Bot 자동화 | B2C 관람객 UX 설계 |
| **강점** | AI 자동화·팝업 차별화와 직결 | 전시 유형별 범용 적용, 사용자 행동 설계 명확 |

```javascript
[Layer 1]  공간 테마 모드 (Concept Bot)   ← "어떤 성격의 팝업을 만들 것인가"
                      ↓  전시 유형 × 테마 조합으로 자동 추천
[Layer 2]  관람객 경험 모듈               ← "팝업 안에서 관람객이 무엇을 하는가"
                      ↓
[Layer 3]  데이터 파이프라인              ← AI 큐레이터 수집 → 팝업 개인화 → 기획사 인사이트
```

## Layer 1 — 공간 테마 모드 (Concept Bot)

기획사가 Concept Bot 실행 시 선택하는 **팝업 공간의 성격**을 정의합니다.

```javascript
Concept Bot
├── Story Mode     — 스토리형     (서사 축)
├── Sensory Mode   — 감각형       (공감각 축)
├── Archive Mode   — 데이터 초상형 (개인화 축)
├── Community Mode — 커뮤니티형   (관계 축)
├── Role Mode      — 역할극형     (참여 축)
└── Time Mode      — 시간여행형   (맥락 축)
```

| 모드명 | 핵심 축 | 팝업 공간 성격 | MVP 적합성 |
| --- | --- | --- | --- |
| Story Mode | 서사·내러티브 | 작품 세계관 또는 작가 삶을 서사로 재현 | ✅ 1순위 |
| Sensory Mode | 공감각·신체 | 시각 외 감각(향·소리·촉감)으로 재해석 | ✅ 1순위 |
| Archive Mode | 개인화·자기표현 | 나의 관람 데이터가 유일한 굿즈가 되는 공간 | ✅ 1순위 |
| Community Mode | 관계·연결 | 같은 취향의 낯선 사람을 연결하는 클럽 | 🔵 v1.0 |
| Role Mode | 참여·몰입 | 관람객이 전시 속 역할을 수행하는 이스케이프룸형 | 🟡 v2.0 |
| Time Mode | 맥락·역사 | 작품의 시대적 배경 속으로 이동하는 공간 | 🟡 v2.0 |

### 테마 모드 상세

**Story Mode**

작품 세계관 확장형(작품 속 가상 세계를 현실 공간으로) 또는 작가 연대기형(작가의 삶을 동선으로 재구성)으로 운영합니다.

```javascript
[입장] 프롤로그 존 → [중간] 절정 존 → [퇴장] 에필로그 존 + 굿즈
```

- AI 자동화: 작품 색감·형태 → 공간 시간대·날씨·인물 설정 → 3막 동선 자동 생성
- 굿즈 방향: "이 세계에서 가져온 물건"이라는 내러티브 부여
- 추가 아이디어: 엔딩 분기형(AI 대화에 따라 마지막 존 연출 변경), 시즌제 운영
**Sensory Mode**

미디어아트의 시각 경험을 역방향으로 접근합니다.

```javascript
[작품 색감] → AI 번역 → [향기 팔레트]
[작품 리듬] → AI 번역 → [사운드스케이프]
[작품 질감] → AI 번역 → [촉각 오브제]
```

- AI 자동화: 작품 이미지 → 색온도·채도를 향기 계열로 매핑 (예: 차가운 딥블루 → 시더우드+민트)
- 결과물: 팝업용 "감각 레시피 북" 자동 생성 (조향사·사운드 아티스트 브리핑)
- 추가 아이디어: "블라인드 관람" 체험존(시각 차단 후 향+소리로 작품 맞추기 → SNS 챌린지)
**Archive Mode**

AI 큐레이터가 수집한 관람 데이터를 오직 나만의 시각적 아카이브로 변환합니다.

| 데이터 입력 | AI 산출물 | 굿즈/체험 |
| --- | --- | --- |
| 체류 시간 TOP 3 작품 | 나만의 "베스트 컬렉션" 포스터 | A3 리소그래프 인쇄 |
| 반복된 감정 키워드 | 키워드로 생성한 추상 비주얼 | 폰케이스·에코백 |
| 대화 히스토리 전체 | 나의 관람을 요약한 "한 줄 시" | 레터프레스 카드 |
| 동선 데이터 | 내가 만든 전시 지도 | 리소 지도 포스터 |

**Community Mode**

취향 클러스터링으로 관람객을 연결합니다.

- AI 자동화: 큐레이터 취향 데이터 → 클러스터링 → 클러스터별 이벤트 초대장 자동 발송
- 공간 장치: 취향 키워드 뱃지 수령, 같은 뱃지 색상 사람과 대화 유도, 두 사람 데이터 합친 콜라보 포스터 제작
**Role Mode**

관람객에게 전시 세계관 안의 직업·역할을 부여합니다.

```javascript
[입장] 역할 배정 → [탐험] 역할별 미션 수행 → [완료] 역할 완수 보상 굿즈
```

- AI 자동화: IP 분석 → 직업·역할 목록 자동 생성 → 역할별 미션 시나리오 자동 작성
- 재방문 구조: 각 역할마다 다른 동선·MD → 한 번 방문으로 모든 역할 체험 불가
**Time Mode**

작품이 만들어진 시대적·문화적 맥락을 재현합니다.

- AI 자동화: 작품 연도·배경 입력 → 해당 시대 문화·유행·사건 조사 → 공간 연출 브리핑 생성
- 추가 아이디어: "미래 시간여행" (이 작품이 100년 후 발견된다면), 시대별 한정 MD

## Layer 2 — 관람객 경험 모듈

팝업 공간 안에서 관람객이 **실제로 하는 행동**을 설계합니다. (공동 작업자 안)

### 모듈 10종 분류

| 구분 | 모듈명 | 핵심 목적 | 활용 데이터 | 사용자 경험 | 적용 난이도 |
| --- | --- | --- | --- | --- | --- |
| **회고형** | 감상 회고 모듈 | 나의 관람 경험을 다시 돌아보게 함 | 감정 태그, 저장 작품, 감상 메모, 관람 순서 | "나는 이 전시를 이렇게 느꼈구나"를 리포트로 확인 | 낮음~중간 |
| **표현형** | 감정 담벼락 모듈 | 감정과 생각을 짧게 남기게 함 | 한줄 감상, 감정 태그, 작품 선택 | 한 줄 감상 작성, 다른 관람객의 문장 확인 | 낮음 |
| **개인화형** | 나만의 큐레이션 모듈 | 관람객의 취향으로 전시를 재구성 | 저장 작품, 관심 키워드, 감정 태그 | 내가 고른 작품으로 나만의 작은 전시 생성 | 중간 |
| **공유형** | 전시 포스터/카드 모듈 | 관람 경험을 이미지 콘텐츠로 공유 | 감상 키워드, 저장 작품, 대표 감정 | 나만의 전시 포스터·감상 카드 생성 | 낮음~중간 |
| **시각화형** | 관람 하이라이트 모듈 | 동선과 체류 경험을 콘텐츠화 | 관람 동선, 체류 시간, 공간별 반응 | 내가 오래 머문 구간을 15초 영상/루트로 확인 | 높음 |
| **집단 반응형** | 집단 반응 지도 모듈 | 다른 관람객의 반응과 내 감상을 비교 | 작품별 감정 태그, 저장 수, 체류 시간 | 사람들이 가장 많이 반응한 작품/구간 확인 | 중간 |
| **참여형** | 투표/질문 모듈 | 전시 메시지에 대한 의견을 수집 | 선택 응답, 감상 키워드, 공감/비공감 | 질문에 답하고 다른 사람들의 선택 확인 | 낮음 |
| **수집형** | 디지털 굿즈 모듈 | 관람의 완성감과 소장 욕구를 제공 | 방문 기록, 미션 완료, 작품 저장, 참여 이력 | 배지, 스티커, 디지털 티켓, 기념 카드 획득 | 중간 |
| **학습형** | 관람 노트/퀴즈 모듈 | 전시 내용을 이해하고 기억하게 함 | 작품 정보, 섹션 정보, 퀴즈 응답 | 관람 내용을 정리하거나 퀴즈로 복습 | 중간 |
| **추천형** | 다음 경험 추천 모듈 | 관람 이후 다음 행동으로 연결 | 감정 태그, 저장 작품, 관심 키워드, 클릭 이력 | 다음 전시, 굿즈, 프로그램, 콘텐츠 추천 | 중간 |

### 상위 목적별 묶음

| 상위 목적 | 해당 모듈 |
| --- | --- |
| **감상을 남기게 하는 모듈** | 감정 담벼락, 감상 회고, 관람 노트 |
| **감상을 콘텐츠로 바꾸는 모듈** | 전시 포스터/카드, 관람 하이라이트, 나만의 큐레이션 |
| **다른 사람과 연결하는 모듈** | 집단 반응 지도, 투표/질문, 감정 담벼락 |
| **다음 행동으로 연결하는 모듈** | 다음 경험 추천, 디지털 굿즈, 프로그램/굿즈 연계 |

### 히스토리

## 들어가며: 왜 "스토리형"인가

v3.0 문서의 Concept Bot은 현재 "IP 분석 기반 컨셉 3종 자동 생성"까지만 정의되어 있습니다. 스토리형 모듈은 여기서 한 발 더 나아가, **관람객이 팝업 공간 안에서 '내러티브의 일부'가 되는 경험**을 설계합니다. 단순한 굿즈 판매가 아니라, 전시의 감동을 서사로 연장하는 것이 핵심입니다.

## 1안: 작품 세계관 확장형 — "작품 속으로"

### 개념 정의

특정 작품 하나를 골라, 그 작품 안에 존재하는 가상의 세계를 현실 공간으로 끌어내는 방식입니다. 관람객은 "이 작품을 본 사람"이 아니라 "이 세계를 살아가는 존재"로 팝업에 입장합니다.

### 상세화 방안

**① IP 분석 레이어 (Concept Bot 확장)**

현재 v3.0의 IP Asset Analyzer가 키워드·톤앤매너를 추출하는 데 그친다면, 스토리형에서는 다음 레이어를 추가합니다.

| 분석 항목 | 기존 | 스토리형 추가 |
| --- | --- | --- |
| 시각 특징 | 색상, 형태 추출 | "이 작품 안에 존재한다면 어떤 감각인가" (촉각/후각/온도 언어화) |
| 세계관 | 톤앤매너 | 공간의 시간대·날씨·인물 설정 |
| 서사 구조 | - | 발단-전개-절정 3막 구조로 팝업 동선 설계 |

**② 팝업 공간 설계 원칙**

공간을 "챕터"로 나눕니다. 관람객은 입장부터 퇴장까지 하나의 짧은 이야기를 체험합니다.

> [입장] 프롤로그 존 → [중간] 절정 존 → [퇴장] 에필로그 존 + 굿즈

> "이 세계에 도착" / "사건의 중심" / "이 세계를 떠나며 가져가는 것"

**③ AI 큐레이터 연계 (Bridge Trigger 강화)**

관람 중 AI 큐레이터가 수집한 취향 데이터를 팝업 챕터 추천에 활용합니다.

- 감정 키워드가 "몽환적·고요"인 관람객 → 프롤로그 존에서 더 오래 머물도록 동선 유도
- 키워드가 "압도적·강렬"인 관람객 → 절정 존의 체험형 콘텐츠로 즉시 안내
**④ 커스텀 MD 설계 원칙**

굿즈는 "이 세계에서 가져온 물건"이라는 내러티브를 가져야 합니다.

| 굿즈 유형 | 일반 접근 | 스토리형 접근 |
| --- | --- | --- |
| 포스터 | 작품 이미지 인쇄 | "챕터 2에서 발견된 편지" 형태의 레터 프레스 |
| 향수/인센스 | 전시 테마 향 | "이 세계의 오전 6시 공기" 라는 이름의 향 |
| 영상 굿즈 | 하이라이트 클립 | 관람객 본인이 "이 세계의 주인공"으로 등장하는 AI 편집 영상 |

### 1안의 추가 아이디어

**A. "엔딩 분기형" 팝업**

관람객이 AI 큐레이터와 나눈 대화 내용에 따라 팝업 마지막 존의 연출이 달라지는 구조. "저는 슬픈 엔딩을 받았어요"라는 SNS 공유 유도 → 자연스러운 바이럴.

**B. 시즌제 운영 구조**

동일한 작품 IP로 "봄 챕터 → 여름 챕터"처럼 테마를 바꿔 재방문을 유도합니다. 기획사 입장에서는 1개 IP로 다회 수익이 가능하다는 점이 설득 포인트가 됩니다.

**C. 작품 내 "미완성 요소" 활용**

작가가 완성하지 않은 부분, 또는 작품 주석에 등장하는 단편적 언급을 팝업 스토리의 "미스터리"로 활용합니다. 관람객이 팝업을 방문해야만 "이 작품의 나머지 이야기"를 알 수 있는 구조.

## 2안: 작가 연대기형 — "작가의 삶을 걷다"

### 개념 정의

작품이 아닌 **작가라는 인간**에 집중합니다. 작가가 이 작품을 만들기까지의 시간 — 자라온 환경, 영향받은 관계들, 결정적 순간들 — 을 팝업 공간에서 재구성합니다. 관람객은 "작품의 관객"에서 "작가의 친구"로 관계가 전환됩니다.

### 상세화 방안

**① 작가 데이터 수집 구조 (신규 모듈 필요)**

현재 v3.0에는 IP 자산(기획서·이미지) 중심의 입력만 정의되어 있습니다. 2안에서는 다음 입력 유형을 추가해야 합니다.

| 데이터 유형 | 수집 방법 | AI 활용 |
| --- | --- | --- |
| 작가 인터뷰·에세이 | 텍스트 업로드 | 성격 키워드·반복 언어 패턴 추출 |
| 작가의 영향을 받은 레퍼런스 | 링크·이미지 | 미적 계보 분석 |
| 작업실·성장 환경 사진 | 이미지 업로드 | 공간 무드 언어화 |
| 주변 인물 (지인·스승·파트너) | 텍스트 정리 | 관계망 시각화 및 캐릭터화 |

**② 공간 구성 원칙: 연대기 동선**

> [1존] 기원 (Origin) → [2존] 전환점 (Turning Point) → [3존] 지금 이 작품 (The Work)

> 작가가 자란 공간·최초의 감각적 기억 / 결정적 만남·사건·작업 방향을 바꾼 순간 / 작품이 탄생한 내면의 풍경

각 존은 **작가의 실제 언어(인터뷰 발췌)**로 벽면을 채우고, AI가 그 언어를 공간 연출 언어로 번역합니다.

**③ "관계 캐릭터" 활용**

작가의 삶에 등장한 인물들을 팝업 속 페르소나로 활용합니다.

| 캐릭터 | 역할 | 팝업 내 구현 방식 |
| --- | --- | --- |
| 스승 | 작가의 첫 미적 기준을 만든 사람 | 해당 스승의 작업실 재현 코너 |
| 오랜 친구 | 작가의 일상어·유머를 아는 사람 | 친구 시점의 에피소드 카드 굿즈 |
| 작가 자신 (어린 시절) | 현재 작품의 원형 | 어린 시절 드로잉과 현재 작품을 나란히 |

**④ AI 큐레이터 연계: "당신과 작가의 교집합 찾기"**

관람 중 AI 큐레이터가 수집한 관람객 취향 데이터와 작가 성격 키워드를 대조하여, 팝업 입장 시 "오늘 당신과 작가의 공통점은 OOO입니다"라는 개인화 메시지를 제공합니다. 공감 기반의 팝업 전환 유도.

### 2안의 추가 아이디어

**A. "작가의 하루" 시간대별 팝업**

작가의 인터뷰에서 추출한 "나는 오전 4시에 작업한다" 같은 디테일을 활용해, 팝업을 오전/심야 타임으로 나누어 운영합니다. 각 타임에 다른 연출과 MD를 배치 → 재방문 구조 자동 생성.

**B. "미완성 작가 노트" 참여형 굿즈**

작가가 실제로 쓰다 만 노트 페이지를 AI가 재현하고, 관람객이 여백을 채워 자신만의 페이지를 완성하는 굿즈. 작가와 관람객이 함께 만든 물건이라는 내러티브.

**C. 작가 연대기 아카이브 구독 모델**

기획사가 AFTERGLOW의 데이터 리포트를 구독하듯, 관람객에게도 "작가의 다음 이야기"를 알림으로 받는 구독 모델을 붙입니다. 팝업 종료 후에도 관람객과의 관계를 유지하는 B2C 리텐션 구조.

## 종합 제안: 모듈 명칭 및 v3.0 통합 위치

두 안은 별개의 서비스가 아니라, **Concept Bot의 하위 스토리 생성 레이어**로 통합하는 것을 추천합니다.

```javascript
Concept Bot
├── [기존] 공간 컨셉 3종 자동 생성
├── [신규] Story Mode A — 작품 세계관 확장형 (1안)
└── [신규] Story Mode B — 작가 연대기형 (2안)
```

기획사(운영자)가 Concept Bot 실행 시 "스토리 모드 선택" 옵션을 고르면, 해당 모드에 맞는 질문 세트와 산출물 템플릿이 자동으로 달라지는 구조로 설계하면 MVP에 자연스럽게 녹일 수 있습니다.
