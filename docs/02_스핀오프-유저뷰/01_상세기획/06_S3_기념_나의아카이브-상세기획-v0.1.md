## 3. 화면 전용 IA & 데이터 상태

### 3-1. IA 노드 및 데이터 구조
```
S3. 기념 (나의 아카이브) (/spinoff/[slug]/archive)

│   ├── 결과 타이틀 ("당신의 심해는 '고요한 압도'였어요")
│   └── 감상 일자 ("2026.07.29 스핀오프 관람 기록")
├── 2. 모자이크 콜라주 카드 (Mosaic Scene Collage)
│   └── 유저가 감상/촬영한 장면들의 가로/세로 콜라주 이미지
├── 3. AI 대화 발췌 소장 카드 (Quote Card)

│   └── (본전시 미관람자 전용) [본전시 〈심해의 환상〉 보러가기 ↗]
└── 6. 완료 푸터 버튼
    └── [여정 완료하고 홈으로 가기] (/spinoff/home 라우팅)
```

## 4. UI/UX 요소 및 인터랙션 상세

### 4-1. 초개인화 소장 카드 (Personalized Card)
* S1 온보딩 키워드 + S2 대화 발췌 조합으로 단 하나뿐인 결과 카드 자동 생성.
* html2canvas 또는 Canvas API 연동으로 1:1 / 9:16 인스타 스토리 규격 이미지 저장 가능.

### 4-2. 마플 POD 굿즈 연계 다이얼로그 (POD Goods Modal)
* `[이 순간, 굿즈로 간직하기]` 클릭 시 아크릴 키링, 미니 포스터 등 커스텀 굿즈 커스텀 모사 다이얼로그 팝업 노출.

### 4-3. 미관람자 대상 본전시 역이동 CTA (Conditional CTA)
* **조건**: `afterglow_spinoff_session.visited_main === false`일 때만 하단에 돋보이는 버건디-시안 믹스 파동 버튼 노출.
* **문구**: `[본전시 〈심해의 환상〉 보러가기 ↗]` (클릭 시 `/exhibition/abyss` 이동).

## 5. 예외 및 에지케이스 처리

* **대화 발췌 데이터가 없을 때**: "빛이 가라앉고 당신만의 조용한 잔상이 남았습니다" 기본 디폴트 명문구 삽입.
* **이미지 저장 권한 거부 시**: 모바일 브라우저 길게 누르기 저장 안내 팝업 노출.
