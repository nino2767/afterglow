## 1. 화면 개요

* **화면 ID**: `S2`
* **라우팅 경로**: `/spinoff/[slug]/viewer`
* **역할**: 스핀오프의 메인 코어 관람 화면. AI가 생성 및 변주한 독립 스핀오프 씬(Scene 1~4)을 감상하고, **관람 중/관람 후에도 끊김 없이 이어지는 AI 큐레이팅 세계관 1:1 심층 토크**를 제공함.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 오버레이 대화창)

## 2. 화면 전용 유저 Flow

```mermaid
flowchart TD
    A[S1 온보딩 완료 후 진입 /viewer] --> B{뷰 모드 선택}
    
    B -- [Swipe Mode] 세로 스와이프 --► C[3~4개 스핀오프 미니 씬 연속 감상]
    C --> D[오버레이 AI 큐레이터 대화 버블 구동]
    
    B -- [List Mode] 작품 목록 --► E[ModularArtworkList 렌더링]
    E --> F[작품 선택 시 ModularDocentPanel 오픈]
    F --> G[[AI 큐레이터 대화 나누기] 클릭 시 심층 1:1 토크 화면 연결]
    
    D & G --> H[관람 후에도 작가/세계관 1:1 심층 대화 수행]
    H --> I[촬영/업로드 사진 기반 자동 아카이브 초안 생성]
    I --> J[[여정 기록하고 아카이브 받기] 클릭 시 S3 아카이브 이동]
```

### Flow 상세 단계
1. **입장**: S1 온보딩에서 전달받은 감정 키워드(예: `고요함`)에 맞춰 나레이션 텍스트 및 분위기가 개인화되어 세팅.
2. **감상**:
   - Swipe Mode: 화면 전체를 채우는 몽환적 장면을 스와이프하며 감상. 하단 오버레이 AI 큐레이터 대화 버블로 메시지 송수신.
   - List Mode: 작품 리스트를 둘러보고 클릭 시 도슨트 설명 패널 및 AI 1:1 대화 모달 진입.
3. **지속 대화**: 관람이 끝난 후에도 작가/세계관에 대해 제한 없이 심층 질문 답변 가능.
4. **아카이브 완료**: 관람 사진 아카이브 초안 생성 후 하단 `[여정 기록하고 아카이브 받기]` 버튼 클릭으로 S3 이동.

## 4. UI/UX 요소 및 인터랙션 상세

### 4-1. Swipe Mode vs List Mode
* **Swipe Mode**: `Framer Motion` / `Swiper.js` 기반 세로 씬 넘김, 뷰포트 전체 몰입 비주얼.
* **List Mode**: 공통 모듈 `ModularArtworkList` 렌더링. 클릭 시 `ModularDocentPanel` 팝업 오픈.

### 4-2. 관람 후 지속 대화 (Continuous AI Chat)
* AI 대화창은 풀스크린 오버레이 모드로 확장 가능.
* 작가의 생애, 비하인드 스토리, 세계관의 뒷이야기 등 **관람이 종료된 후에도 제한 없이 1:1 대화를 지속**할 수 있음.

### 4-3. 현장 사진 아카이브 자동화 (Photo Auto-Archive)
* 카메라 버튼 클릭 시 업로드한 사진 또는 캡처 사진이 즉시 AI에 의해 감정 태깅 및 리뷰 초안 문구로 변환되어 저장됨.
