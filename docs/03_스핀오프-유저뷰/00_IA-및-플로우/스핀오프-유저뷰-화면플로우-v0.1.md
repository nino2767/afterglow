## 2. 유저 경험 궤적 시퀀스 다이어그램 (Experience Sequence)

```mermaid
sequenceDiagram
    autonumber
    actor User as 관람객 (User)
    participant S0 as S0 포스터 / S1 온보딩
    participant Auth as S-0 Auth-Wall (로그인)
    participant S2 as S2 씬 뷰어 & AI 큐레이터
    participant DB as 회원 DB / 세션
    participant S3 as S3 아카이브

    User->>S0: 1. 포스터 감상 및 감정 키워드 시드 2개 선택
    User->>S0: 2. [관람 시작하기] 클릭
    
    alt 미로그인 유저
        S0->>Auth: 3. S-0 로그인 모달 구동 (Auth-Wall)
        User->>Auth: 4. 3초 소셜 간편 로그인 (카카오/네이버/Google)
        Auth->>DB: 5. 게스트 키워드 데이터 ➔ 회원 계정으로 자동 병합
    end

    Auth->>S2: 6. S2 코어 씬 뷰어 자동 전이
    User->>S2: 7. 미니 씬 감상 & AI 큐레이터와 1:1 심층 대화
    S2->>DB: 8. 대화 내용 & 촬영 사진 감정 분석 저장

    User->>S3: 9. [여정 기록받기] ➔ S3 나의 아카이브 전이
    S3->>User: 10. 감정 모자이크 카드 & AI 대화 발췌 소장 카드 렌더링
    
    opt SNS 공유 / 굿즈 확인
        User->>S3: 11. 이미지 캡처/다운로드 & 출구 굿즈 안내 팝업 확인
    end

    opt 본전시 미관람 유저
        User->>S3: 12. [본전시 보러가기 ↗] ➔ S1.5 본전시 상세/예매 역이동
    end
```

## 3. 서사적 단계별 주요 가치 명세

1. **발견 & 입장 (S-1, S0, S1)**: 무장벽(Zero-Barrier) 진입으로 부담을 지우고 감정 선택만으로 세계관에 즉시 몰입.
2. **인증 & 코어 관람 (S-0, S2)**: 3초 소셜 로그인으로 회원 리드를 확보한 후, 끊김 없는 AI 1:1 대화로 세계관 경험 제공.
3. **기념 & 시너지 (S3, S1.5)**: 나의 감정 모자이크 소장 카드 발급 및 본전시 예매 시너지 역이동 완성.
4. **여운 (S4, S-My)**: D+2 리마인드 및 마이페이지 아카이브 갤러리에서 지속적인 관람 여운 유지.
