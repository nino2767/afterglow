## 1. 화면 개요

* **화면 ID**: `S05`
* **라우팅 경로**: `/spinoff/[slug]/viewer`
* **역할**: 유저 여정 5단계 (코어). 스핀오프의 메인 씬(Scene 1~4)을 감상하고, **관람 중 및 관람 후에도 제한 없이 이어지는 AI 큐레이터와의 1:1 심층 세계관 토크**를 제공함.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 오버레이 대화창)

## 2. 서비스 정책 (Policies)

* **2-1. 회원 전용 접근 정책 (Auth-Wall 보호)**:
  * 본 화면은 S04 로그인을 완료한 회원 유저만 진입 가능.
  * 비로그인 접근 시 S03 온보딩 및 S04 로그인 모달로 강제 리다이렉트.
* **2-2. AI 토큰 오남용 방지 정책**:
  * 유저 1인당 1:1 대화 턴 수 및 맥락 유지 메모리를 회원 계정에 바인딩.
* **2-3. 네비게이션 정책**: 상단 GNB 뷰모드 토글 + 햄버거(`☰`), 하단 바텀 네비 미사용.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S05. 관람 (씬 뷰어) (/spinoff/[slug]/viewer)
├── 1. 뷰 모드 토글바 -> [몰입형 뷰] (Swipe) / [목록형 뷰] (List)
├── 2. 메인 씬 영역 -> 장면 카드 (Scene 1~4) & 개인화 나레이션
├── 3. AI 큐레이터 오버레이 챗 -> 1:1 스트리밍 대화, 입력창, 카메라 버튼
└── 4. 하단 완료 CTA -> [여정 기록하고 아카이브 받기]
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S05-01` | 세로 스와이프 | 세로 터치 스와이프로 씬 1~4 변경 | Swipe Mode |
| `FN-S05-02` | AI 1:1 대화 | 질문 입력 시 SSE 스트리밍 방식으로 큐레이터 응답 | **회원 전용** |
| `FN-S05-03` | 사진 아카이브화 | 카메라 버튼으로 사진 업로드 시 자동 감정 분석 및 저장 | 스냅 생성 |
