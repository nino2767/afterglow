## 1. 화면 개요

* **화면 ID**: `S-0`
* **라우팅 경로**: `/spinoff/login` (또는 S1 온보딩에서 S2 진입 시 구동되는 풀모달)
* **역할**: S2 관람 및 AI 큐레이터 1:1 대화 코어 서비스 진입 전 필수 인증(Auth-Wall) 관문이자, 3초 소셜 간편 가입/로그인을 통해 관람 세션 데이터를 회원 계정에 영속화시키는 화면.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 인증 모달)

## 2. 서비스 정책 (Policies)

### 2-1. 회원 가입 정책 (Sign-up Policies)
* **소셜 간편 가입**: 카카오톡, 네이버, Google OAuth 2.0 연동 3초 가입. 별도 아이디/비밀번호 생성 과정 없음.
* **필수 서비스 약관 동의**:
  1. `[필수]` 서비스 이용약관 및 만 14세 이상 확인
  2. `[필수]` 개인정보 수집 및 이용 동의 (이메일, 프로필 닉네임)
  3. `[필수]` AI 대화 큐레이팅 데이터 학습 활용 동의
* **닉네임 부여 정책**: 가입 시 소셜 닉네임을 디폴트 세팅하며, 비워둘 경우 형용사+명사 조합(예: `고요한 윤슬`)으로 자동 생성 (마이페이지에서 수정 가능).

### 2-2. Auth-Wall 트리거 시점 정책 (Trigger Policies)
* 게스트 유저가 S1 온보딩에서 `[관람 시작하기]` 클릭 시 자동 구동.
* 로그인 완료 시 유저가 탐색하던 스핀오프 S2 씬 뷰어(`/viewer`)로 자동 전이.

### 2-3. 세션 데이터 병합 정책 (Session Merge)
* 비로그인 상태에서 온보딩(S1) 시 선택한 감정 키워드/기억 장면 시드 데이터(`afterglow_spinoff_session`)는 소셜 가입/로그인 완료 직후 즉시 생성된 회원 계정(`afterglow_account`)에 100% 귀속/병합됨.

## 3. 화면 전용 유저 Flow

```mermaid
flowchart TD
    A[S1 온보딩에서 [관람 시작하기] 클릭] --> B{로그인 여부 체크}
    B -- (미로그인 상태) --► C[S-0 로그인/가입 모달 구동 /spinoff/login]
    
    C --> D[소셜 로그인 버튼 선택: 카카오 / 네이버 / Google]
    D --> E[OAuth 2.0 소셜 인증 동의]
    E --> F{기존 회원 여부}
    
    F -- (신규 가입 유저) --► G[필수 약관 동의 & 닉네임 확인]
    G --> H[회원 계정 생성 & 게스트 세션 데이터 자동 병합]
    
    F -- (기존 회원 유저) --► H
    
    H --> I[S2 관람 씬 뷰어 /spinoff/[slug]/viewer 자동 전이]
```

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S-0. 계정 로그인 및 가입 (/spinoff/login)
├── 1. 모달 헤더 -> 로고 "AFTERGLOW", 닫기 버튼
├── 2. 안내 텍스트 -> "AI 큐레이터 1:1 대화 및 스핀오프 감상을 위해 3초 소셜 로그인이 필요합니다"
├── 3. 소셜 로그인 버튼 그룹
│   ├── [카카오로 시작하기] (노란색 카카오 그라디언트) -> 1순위
│   ├── [네이버로 시작하기] (초록색 네이버)
│   └── [Google로 시작하기] (화이트 다크 틴트)
└── 4. 필수 약관 동의 수렴 라인 -> 이용약관, 개인정보, AI 데이터 활용 동의
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S0-01` | 소셜 OAuth 인증 | 클릭 시 카카오/네이버/Google OAuth 팝업 구동 및 인증 토큰 발급 | 소셜 간편인증 |
| `FN-S0-02` | 세션 자동 병합 | 로컬스토리지 게스트 키워드 데이터 ➔ 생성된 회원 계정에 바인딩 | 세션 영속화 |
| `FN-S0-03` | 닉네임 자동 생성 | 프로필명 누락 시 무작위 300종 형용사+명사 조합 닉네임 자동 할당 | 기본 프로필 |
