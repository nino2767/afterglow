## 1. 화면 개요

* **화면 ID**: `S0`
* **라우팅 경로**: `/spinoff/[slug]` (예: `/spinoff/abyss-wave`)
* **역할**: 특정 스핀오프 전시의 키비주얼과 컨셉을 한 화면으로 보여주는 디지털 포스터. 본전시 미관람자도 부담 없이 독립된 두 번째 작품으로 즉시 관람 입장을 유도함.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 시안 `#4FD8EB` / 앰비언트 비주얼 배경)

## 2. 화면 전용 유저 Flow

```mermaid
flowchart TD
    A[S-1 홈 / 외부 QR / SNS 링크 유입] --> B[S0 디지털 포스터 화면 진입 /spinoff/abyss-wave]
    B --> C{유저 액션}
    C -- [입장하기] 버튼 클릭 --► D[S1 입장 온보딩 /spinoff/abyss-wave/onboarding 이동]
    C -- [원작 전시 정보 ↗] 링크 클릭 --► E[S1.5 본전시 상세페이지 /exhibition/abyss 이동]
    C -- [상단 닫기 X] 클릭 --► F[S-1 서비스 홈으로 복귀]
```

### Flow 상세 단계
1. **유입**: 외부 SNS 공유 링크, QR 코드, 또는 S-1 홈 카드를 통해 `/spinoff/abyss-wave`로 이동.
2. **몰입**: 화면 가득 몽환적인 심해 앰비언트 비주얼과 세리프 체 전시 타이틀을 감상.
3. **입장 분기**: `[입장하기]` 클릭 시 S1 온보딩(`/onboarding`)으로 진입. 본전시가 궁금한 경우 푸터링크로 S1.5 이동 가능.

## 4. UI/UX 요소 및 인터랙션 상세

### 4-1. 키비주얼 앰비언트 배경 (Ambient Background)
* CSS `radial-gradient`와 Keyframe 애니메이션을 사용하여 깊은 바다 속 빛 무리가 천천히 움직이는 앰비언트 효과 구현.
* 성능 최적화를 위해 CSS HW 가속 (`transform: translateZ(0)`) 활용.

### 4-2. 포스터 텍스트 & 타이포그래피 (Poster Typography)
* **태그**: `SPIN-OFF EXHIBITION` (시안 글로우 텍스트, `letter-spacing: 0.15em`)
* **전시 타이틀**: 《심해의 환상 : 두 번째 물결》 (`Playfair Display`, `32px`, Bold)
* **서브 카피**: "당신이 미처 만나지 못한 심해의 네 장면." (`15px`, Regular, `opacity: 0.85`)

### 4-3. 핵심 CTA 버튼 (Primary CTA Button)
* **버튼 문구**: `[입장하기]`
* **스타일**: `height: 54px`, `border-radius: 27px`, `background: linear-gradient(135deg, #4FD8EB 0%, #2A7F96 100%)`, `color: #0D0D0F`, Bold.
* **인터랙션**: 클릭 시 입자 가루 스프레드 효과 후 `/onboarding` 페이지로 이동.

## 5. 예외 및 에지케이스 처리

* **유효하지 않은 slug인 경우**: "존재하지 않는 스핀오프 전시입니다" 메시지 출력 후 S-1 서비스 홈으로 이동.
* **공유 버튼 클릭 시**: `navigator.share()` API 구동, 미지원 브라우저 시 클립보드 URL 복사 완료 토스트 노출.
