## 1. 화면 개요

* **화면 ID**: `S0`
* **라우팅 경로**: `/spinoff/[slug]` (예: `/spinoff/abyss-wave`)
* **역할**: 개별 스핀오프 전시의 키비주얼과 컨셉을 한 화면으로 보여주는 모바일 디지털 포스터.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 시안 `#4FD8EB` / 앰비언트 모션 배경)

---

## 2. 서비스 정책 (Policies)

* **2-1. 티저 무장벽 정책**: 본전시 관람 여부 및 로그인 여부와 관계없이 게스트도 자유롭게 세계관 비주얼과 카피를 감상할 수 있음.
* **2-2. 진입 라우팅 정책**: 파라미터 `slug`가 유효하지 않을 경우 S-1 홈으로 안전 리다이렉트.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S0. 발견 (디지털 포스터) (/spinoff/[slug])
├── 1. 가이드 헤더 -> 홈/뒤로가기 버튼, 공유 버튼
├── 2. 키비주얼 히어로 -> 태그 "SPIN-OFF EXHIBITION", 전시명, 감성 메인 카피
├── 3. 메인 CTA 버튼 -> [입장하기] (글로잉 시안 보더)
└── 4. 원작 출처 안내 푸터 -> "원작 전시 · 심해의 환상 | 본전시를 안 봤어도 입장할 수 있어요"
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S0-01` | 입장하기 클릭 | 클릭 시 S1 온보딩 페이지(`/onboarding`)로 라우터 이동 | 코어 이동 |
| `FN-S0-02` | SNS 공유 | `navigator.share()` API 구동 (미지원 시 URL 클립보드 복사) | 바이럴 |
| `FN-S0-03` | 원작 링크 클릭 | 원작 본전시 상세 페이지(`/exhibition/abyss`)로 이동 | 시너지 |
