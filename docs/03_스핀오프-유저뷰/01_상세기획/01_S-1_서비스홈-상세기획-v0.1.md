## 1. 화면 개요

* **화면 ID**: `S-1`
* **라우팅 경로**: `/spinoff/home`
* **역할**: 플랫폼 메인 첫 화면이자 상영 중인 스핀오프 전시 라인업 소개, 데모 전시 진입점 및 B2B 제안 랜딩.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 시안 `#4FD8EB` / 딥 메탈릭 `#0D0D0F`)

---

## 2. 서비스 정책 (Policies)

* **2-1. 접근 정책 (Zero-Barrier)**: 로그인 유무와 상관없이 비로그인 게스트도 자유롭게 접속 및 라인업 탐색 가능.
* **2-2. 디스플레이 및 뷰포트 정책**:
  * 모바일웹/웹앱 전용 (`max-width: 430px` 센터링).
  * PC 접속 시 화면 중앙에 모바일 뷰포트 레이아웃 고정, 좌우 영역 앰비언트 블러 어둠 처리.
* **2-3. B2B 제안 정책**: B2C 관람 몰입감을 저해하지 않도록 화면 가장 하단에 소형 정적 텍스트로 문의 링크 노출.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S-1. 서비스 홈 (/spinoff/home)
├── 1. 브랜드 헤더 (Brand Header) -> 로고 "AFTERGLOW", 프로필/로그인 아이콘
├── 2. 큐레이션 섹션 (Showcase) -> "지금 상영 중인 스핀오프" 타이틀 & 라인업 카드
└── 3. 푸터 B2B 섹션 (Footer) -> "기획사 스핀오프 제안 및 파트너십 문의 ↗"
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S1-01` | 라인업 카드 클릭 | 클릭 시 해당 스핀오프 포스터 페이지(`/spinoff/[slug]`)로 라라우터 전이 | 메인 1순위 |
| `FN-S1-02` | 프로필/로그인 클릭 | 비로그인 시 S-0 로그인 모달 구동, 로그인 시 S-My 마이페이지로 이동 | 상단 헤더 |
| `FN-S1-03` | B2B 제안 팝업 | 문의 링크 클릭 시 이메일 폼 모달 구동 | B2B 파트너십 |
