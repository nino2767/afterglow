## 1. 화면 개요

* **화면 ID**: `S-My`
* **라우팅 경로**: `/spinoff/mypage`
* **역할**: 관람객 본인의 본전시 Pass 티켓, 스핀오프 아카이브 카드 갤러리, AI 큐레이터 대화 히스토리 및 **회원 프로필 수정 / 회원 탈퇴 관리**를 총괄하는 회원 전용 아카이브 룸.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 마이 아카이브 갤러리 레이아웃)

---

## 2. 서비스 정책 (Policies)

### 2-1. 회원 탈퇴 및 데이터 삭제/파기 정책 (Withdrawal Policies - 중요)
* **회원 탈퇴 버튼 위치**: 마이페이지 하단 계정 관리 영역에 `[회원 탈퇴하기]` 링크배치.
* **탈퇴 절차 (2-Step)**:
  1. `[회원 탈퇴하기]` 클릭 ➔ 탈퇴 유의사항 안내 다이얼로그 모달 구동
  2. "탈퇴 시 저장된 나의 아카이브 카드, AI 대화 히스토리 및 보관함 Pass 데이터가 즉시 파기되며 복구 불가능함" 필수 체크 동의
  3. `[계정 삭제 및 즉시 탈퇴]` 최종 확인 클릭
* **데이터 파기 범위**:
  - 회원 프로필, 로그인 토큰, 소셜 연동 정보 DB 및 로컬스토리지 즉시 파기 (`afterglow_account`, `user_snaps` 파기).
  - 전자상거래법에 따른 결제 기록(본전시 티켓 예매 등)은 5년간 익명화 상태로 법정 보관.
* **탈퇴 완료 처리**: 세션 쿠키/로컬스토리지 전면 초기화 후 서비스 홈(`/spinoff/home`)으로 즉시 리다이렉트 및 "회원 탈퇴가 완료되었습니다" 안내 토스트 출력.

### 2-2. 프로필 수정 정책
* 닉네임은 언제든지 변경 가능하며, 중복 검사 없이 최대 12자까지 허용.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S-My. 마이페이지 (/spinoff/mypage)
├── 1. 프로필 정보 탭 -> 소셜 뱃지, 닉네임 (수정가능), 로그아웃 버튼
├── 2. 티켓 보관함 탭 -> 본전시 Pass 바코드, 스핀오프 초대장 카드
├── 3. 나의 아카이브 갤러리 탭 -> 생성했던 초개인화 소장 카드 갤러리 (다운로드/공유)
├── 4. AI 큐레이터 대화 탭 -> 과거 1:1 대화 목록 & 다시 읽기
└── 5. 계정 관리 푸터 -> [회원 탈퇴하기] (즉시 파기 모달 연동)
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-SMy-01` | 닉네임 수정 | 닉네임 인라인 편집 ➔ 즉시 저장 | 프로필 |
| `FN-SMy-02` | 아카이브 다시보기 | 카드 선택 시 S3 아카이브 뷰어로 이동 | 갤러리 |
| `FN-SMy-03` | 회원 탈퇴 | 탈퇴 팝업 ➔ 동의 후 DB/세션 데이터 파기 ➔ S-1 이동 | **탈퇴 정책** |

## 5. UI/UX 인터랙션 및 에지케이스

* **갤러리 그리드 모션**: 모자이크 카드가 2열 그리드로 보여지며 터치 시 글로우 확대 모션.
* **에지케이스**: 저장된 아카이브가 없을 시 "아직 관람 기록이 없어요. 첫 스핀오프를 만나보세요" 텅 뷰(Empty state) 출력.
