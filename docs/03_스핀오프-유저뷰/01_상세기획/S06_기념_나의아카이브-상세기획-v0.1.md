## 1. 화면 개요

* **화면 ID**: `S06`
* **라우팅 경로**: `/spinoff/[slug]/archive`
* **역할**: 유저 여정 6단계. 관람 결과물인 초개인화 소장 카드/리포트를 확인하고, SNS 공유 및 출구 굿즈 소개 팝업, 본전시 미관람 유저 대상 예매 역이동 시너지를 제공하는 종합 피날레 화면.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 아카이브 카드 UI)

## 2. 서비스 정책 (Policies)

* **2-1. 소장 카드 공유 정책**: 감정 모자이크 카드 및 AI 대화 발췌문 카드는 1:1 및 9:16 인스타 스토리 규격으로 이미지 즉시 저장/다운로드 가능.
* **2-2. 1차 MVP 굿즈 정책**: `[출구 굿즈 보기]` 클릭 시 현장 출구 굿즈 1~2종 소개 다이얼로그 팝업 노출.
* **2-3. 미관람자 대상 본전시 역이동 CTA 정책**: S03 온보딩 미관람 유저(`seen_main_exhibition === false`)에게만 하단 강조 CTA 노출.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S06. 기념 (나의 아카이브) (/spinoff/[slug]/archive)
├── 1. 초개인화 아카이브 헤더 -> 결과 타이틀 ("당신의 심해는 '고요한 압도'였어요")
├── 2. 모자이크 콜라주 카드 -> 감상/촬영 장면 가로/세로 콜라주
├── 3. AI 대화 발췌 소장 카드 -> 1:1 대화 최적 발췌문 문장 카드
├── 4. 액션 버튼 그룹 -> [공유 카드 만들기], [출구 굿즈 보기] (팝업)
├── 5. [조건부] 본전시 역이동 CTA -> [본전시 〈심해의 환상〉 보러가기 ↗] (S09 이동)
└── 6. 푸터 버튼 -> [여정 완료하고 홈으로 가기] (S01 이동)
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S06-01` | 이미지 캡처/공유 | `html2canvas`로 소장 카드 PNG 캡처 및 이미지 다운로드 | 공유 |
| `FN-S06-02` | 굿즈 팝업 | 클릭 시 미니 스핀오프 출구 굿즈 1~2종 이미지 모달 팝업 구동 | **MVP 1차** |
| `FN-S06-03` | 본전시 역이동 | 미관람자 대상 클릭 시 S09 본전시 상세(`/exhibition/abyss`) 전이 | 시너지 |
