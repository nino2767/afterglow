## 1. 화면 개요

* **화면 ID**: `S03`
* **라우팅 경로**: `/spinoff/[slug]/onboarding`
* **역할**: 유저 여정 3단계. 본전시 관람 여부 분기, 감정 키워드/기억 장면 시드 선택 및 **S05 코어 관람 진입 전 필수 로그인(S04 Auth-Wall) 전이** 관문.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 분기 선택 카드 UI)

---

## 2. 서비스 정책 (Policies)

* **2-1. Auth-Wall 필수 전환 정책**:
  * 온보딩 키워드 선택 후 `[관람 시작하기]` 클릭 시, **미로그인 유저에게 S04 로그인 모달/화면 구동**.
  * 비즈니스 이유: AI LLM 대화 API 비용의 무분별한 오남용 방지 및 코어 씬 감상 전 유저 회원 가입자(리드) 확충.
* **2-2. 취향 선택 필수 정책**: 감정 키워드 또는 기억 장면 중 최소 1개 이상 선택해야 시작 버튼 활성화.

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S03. 입장 (온보딩) (/spinoff/[slug]/onboarding)
├── 1. 스텝 인디케이터 ("STEP 1 / 2 - 당신의 취향 설정")
├── 2. 관람 유무 선택 라디오 그룹 -> 미관람 키워드 칩 / 관람 기억 장면 선택
├── 3. 데이터 수집 동의 라인 -> 동의 체크박스

```

| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S03-01` | 키워드 토글 | 감정 키워드 칩 클릭 시 선택/해제 (최대 3개) | 시드 수집 |
| `FN-S03-02` | 관람 시작 클릭 | 로그인 상태 검사 ➔ 미로그인 시 S04 로그인 모달 팝업 구동 | **Auth-Wall** |
