## 1. 화면 개요

* **화면 ID**: `S10`
* **라우팅 경로**: `/spinoff/about`
* **역할**: S01 서비스 홈의 브랜드 스토리 배너 또는 슬라이드 메뉴바에서 연결되는 **AFTERGLOW 브랜드 철학 및 세계관 확장 원리 소개 페이지**.
* **디자인 테마**: 스핀오프 시안 펄스 테마 (`theme: "spinoff"`, 글로잉 스토리 카드 UI)

---

## 2. 서비스 정책 (Policies)

* **2-1. 브랜딩 가이드 정책**: 스핀오프 전시가 본전시의 부록이 아니라 "독립된 두 번째 작품"임을 유저에게 매력적인 인터랙션 카드로 전달.
* **2-2. 뷰포트 & 네비게이션 정책**: 상단 GNB 뒤로가기(`←`) + 햄버거(`☰`), 하단 바텀 네비 미사용.

---

## 3. 화면 전용 유저 Flow

```mermaid
flowchart TD
    A[S01 브랜드 배너 / 슬라이드 메뉴바 ➔ 서비스 소개 클릭] --> B[S10 서비스 소개 진입 /spinoff/about]
    B --> C[1. 브랜드 비전: 전시가 끝난 곳에서 이야기는 이어집니다]

    B --> E[3. 관람 가이드: S02 발견 ➔ S03 온보딩 ➔ S05 관람 ➔ S06 아카이브]
    B --> F[하단 [지금 상영 중인 작품 보러가기] 클릭 ➔ S01 서비스 홈 이동]
```

## 4. 화면 전용 IA & 기능 정의 (Function Specs)

### 4-1. IA 노드 구조
```
S10. 스핀오프 서비스 소개 (/spinoff/about)
├── 1. 상단 네비게이션 -> 뒤로가기 버튼, 타이틀 "서비스 소개", 햄버거 버튼 (☰)
├── 2. 히어로 브랜드 세션 -> 비전 한 줄 카피 & 앰비언트 키비주얼
├── 3. 3대 가치 섹션 -> 카드 3종 (독립 작품 / AI 큐레이팅 / 초개인화 소장)
├── 4. 유저 여정 가이드 섹션 -> S02~S07 4단계 관람 아크 설명
└── 5. 푸터 버튼 -> [상영작 보러가기] (S01 홈 전이)
```

### 4-2. 주요 기능 명세
| 기능 ID | 기능명 | 동작 명세 | 비고 |
|---|---|---|---|
| `FN-S10-01` | 상영작 보러가기 | 하단 버튼 클릭 시 S01 서비스 홈(`/spinoff/home`)으로 이동 | 라우팅 |
| `FN-S10-02` | 가치 카드 슬라이드 | 3대 가치 터치 스와이프 인터랙션 카드 | 비주얼 |

---

## 5. UI/UX 인터랙션 및 에지케이스

* **스크롤 페이드인 모션**: 스크롤 내릴 때 브랜드 가치 카드가 부드럽게 시안 빛을 띠며 떠오르는 모션.
* **에지케이스**: 오프라인 상태에서도 기본 브랜드 소개 문구가 로컬 렌더링됨.
