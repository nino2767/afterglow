# 스핀오프 유저뷰 공통 네비게이션 명세서 v0.1

> 작성일: 2026.07.29 | 상태: 📋 정식 확정 (극간결 GNB & 우측 슬라이드 드로어 단일화)
> 적용 범위: 스핀오프 유저뷰 전체 화면 (S-1 ~ S4, S-0, S-My, S1.5)

---

## 1. 네비게이션 원칙 및 아키텍처 (Principles)

* **하단 바텀 네비 미사용 (No Bottom Nav Bar)**: 모바일 뷰포트 하단을 100% 비워 예술 씬과 AI 대화에 100% 몰입하도록 함.
* **극간결 상단 GNB (Minimal Header GNB)**: 상단 헤더 우측에는 단 하나의 **햄버거 메뉴 버튼(`☰`)**만배치하여 아이콘 시각 복잡도를 제거.
* **우측 슬라이드 햄버거 메뉴바 (Slide Menu Drawer)**: 우측 햄버거 버튼(`☰`) 클릭 시 부드럽게 열리는 단일 메뉴바 내에 프로필, 홈, 마이페이지, 브랜드 소개, 약관 등 모든 이동 경로를 일원화함.

---

## 2. 상단 GNB 명세 (Global Navigation Bar)

* **높이 & 레이아웃**: `height: 56px`, `padding: 0 16px`, `backdrop-filter: blur(12px)` (투명 매트 다크 배경).
* **좌측 영역**: `AFTERGLOW` 로고 (글로잉 세리프 폰트 `Playfair Display`, 클릭 시 `/spinoff/home` 홈으로 이동).
* **우측 영역**: 단 하나의 햄버거 메뉴 아이콘 버튼 (`☰`, `width: 24px`, `height: 24px`).

```
[ 상단 GNB 구조 ]
┌─────────────────────────────────────────────────────────┐
│ AFTERGLOW                                            ☰ │
└─────────────────────────────────────────────────────────┘
```

---

## 3. 우측 슬라이드 햄버거 메뉴바 명세 (Slide Menu Drawer)

* **진입 방식**: GNB 우측 햄버거 버튼(`☰`) 터치 시 우측에서 슬라이드 인 애니메이션 (`transition: transform 0.3s cubic-bezier(...)`).
* **너비**: 모바일 뷰포트의 `85%` 너비 (`max-width: 360px`), 좌측 블러 어둠 오버레이 배경.

### 3-1. 메뉴바 구성 항목 명세 (Drawer Items)

```
┌─────────────────────────────────────────────────────────┐
│ [✕ 닫기]                                               │
│                                                         │
│ 👤 고요한 윤슬 님 (회원)                                 │
│    [마이페이지 바로가기 ➔]                              │
│ ─── ─── ─── ─── ─── ─── ─── ─── ─── ─── ─── ─── ─── ─── │
│ 🏠 서비스 홈              /spinoff/home                 │
│ 👤 마이페이지 & 보관함    /spinoff/mypage               │
│ ℹ️ 서비스 소개            /spinoff/about                │
│ ❓ 고객안내 & 약관        /spinoff/terms                │
│                                                         │
│ (하단 정적 링크) 기획사 스핀오프 제안 문의 ↗              │
└─────────────────────────────────────────────────────────┘
```

|---|---|---|---|
