# 디자인명세 — 어드민 고도화 화면 (UI/UX Specification)

> 버전: v1.0 | 작성일: 2026.06.16 | 담당: **@다올** (UI/UX)  
> 연관 기획: [conceptbot-mode-spec.md](./conceptbot-mode-spec.md), [상세기획 - 정산 관리 및 RS 모델 고도화](./상세기획%20-%20정산%20관리%20및%20RS%20모델%20고도화.md)

본 문서는 AFTERGLOW B2B 어드민 콘솔의 고도화 대상 핵심 화면인 **Concept Bot 설정 화면**과 **정산 관리 화면**의 레이아웃 가이드 및 UI 와이어프레임을 상세히 정의합니다.

---

## 1. 디자인 원칙 및 테마 (Design Principles)

* **Deep Blue & Glassmorphism:** 전체 어드민은 미디어아트의 신비롭고 깊이 있는 느낌을 전달하기 위해 다크 모드 테마(`#0D1117`, `#161B22`)를 기본으로 하며, 주요 카드 컴포넌트는 투명도와 블러가 가미된 글래스모피즘(Glassmorphism) 스타일을 적용합니다.
* **Harmonious Palette:** 
  - 주조색 (Primary): `Indigo / Royal Blue` (`#4F46E5`, `#3B82F6`)
  - 포인트색 (Accent): `Soft Violet` (`#8B5CF6`) / `Mint Green` (`#10B981`)
  - 경고/위험 (Alert): `Rose Red` (`#EF4444`)
* **Responsive Layout:** 데스크톱(1920px) 환경을 최우선으로 하되, 태블릿 및 모바일 가로 뷰(최소 768px)까지 그리드가 유연하게 재배치되는 반응형 구조를 채택합니다.

---

## 2. Concept Bot UI/UX 명세

운영자가 전시 IP를 업로드한 직후 진입하는 `ConceptBot.jsx`의 세부 레이아웃입니다.

### 2-1. Step 1: 전시 유형 선택 (Grid Card UI)
10가지 전시 유형 중 하나를 선택하는 영역으로, 2단 그리드로 배치된 10개의 비주얼 카드로 구성됩니다.

```
┌────────────────────────────────────────────────────────────────────────────────┐
│ 1. 전시 유형 선택 (Exhibition Type)                                            │
├────────────────────────────────────────────────────────────────────────────────┤
│ ┌────────────────────────┐  ┌────────────────────────┐  ┌────────────────────┐ │
│ │  🎬 미디어아트 · 몰입형   │  │  🎨 일반 미술전          │  │  🌟 팬덤 · IP 전시  │ │
│ │  [추천] Sensory+Archive │  │  [추천] Story          │  │  [추천] Story+Comm │ │
│ │  감각을 자극하는 전시   │  │  작가의 세계를 감상함  │  │  팬과 아티스트 연결│ │
│ │   [선택하기]             │  │   [선택하기]             │  │   [선택하기]         │ │
│ └────────────────────────┘  └────────────────────────┘  └────────────────────┘ │
│ (총 10개 카드 그리드 형태 배치...)                                               │
└────────────────────────────────────────────────────────────────────────────────┘
```

* **카드 디자인 컴포넌트 스펙:**
  - **Hover Interaction:** 카드 위에 마우스 오버 시 테두리에 보라색 그라데이션(`Linear-Gradient`) 조명 효과가 발생하며, 스케일이 미세하게 확대(`scale(1.02)`)되는 애니메이션 탑재.
  - **추천 태그 (Recommended Badge):** AI가 추천하는 최적의 테마 모드 매핑을 보여주는 서브 태그 제공.

---

### 2-2. Step 2 & 3: 패키지 확인 및 커스터마이징 (2-Column Split View)
전시 유형을 선택하면 화면 하단에 **패키지 자동 매핑 뷰**가 드러납니다. 

* **좌측 컬럼 (Layer 1 테마 설정):** 추천된 테마 모드 상세 설명 및 추가 질문 폼이 노출됩니다. (예: `Story Mode` 선택 시 `세계관 확장형` vs `작가 연대기형` 드롭다운 선택 필드 및 추가 정보 기입 폼 활성화)
* **우측 컬럼 (Layer 2 경험 모듈 선택):** 기본 적용 모듈(체크 표시 고정)과 추가 적용 가능한 확장 모듈(스위치 ON/OFF 토글)이 카드 형식으로 배치되어 자유롭게 커스터마이징할 수 있습니다.

```
┌──────────────────────────────────────────┬─────────────────────────────────────┐
│ 좌측 컬럼: Layer 1 공간 테마 설정         │ 우측 컬럼: Layer 2 경험 모듈 선택    │
├──────────────────────────────────────────┼─────────────────────────────────────┤
│ * 적용 패키지: Words Afterglow Package   │ [기본 적용 모듈 (제외 불가)]       │
│ * 테마 모드: Story Mode (세계관 확장형)  │  ☑️ 감정 담벼락 모듈                 │
│                                          │  ☑️ 나만의 큐레이션 모듈            │
│ ┌──────────────────────────────────────┐ │  ☑️ 전시 포스터/카드 모듈            │
│ │ 추가 질문 (Additional Fields)         │ │ [확장 추천 모듈 (토글형)]            │
│ │ * 세계관 키워드: [심해] [고요함]       │ │  🔘 감상 회고 모듈            [ON ] │
│ │ * 대상 작품명: [빛의 심연]            │ │  🔘 집단 반응 지도 모듈      [OFF] │
│ └──────────────────────────────────────┘ │                                     │
└──────────────────────────────────────────┴─────────────────────────────────────┘
```

## 3. 정산 관리 UI/UX 명세

파트너사 또는 운영자 어드민의 정산 세션을 위한 `Settlement.jsx`의 세부 레이아웃입니다.

### 3-1. 최상단 지표 카드 (KPI Widgets)
상단에는 핵심 성과 지표(KPI)가 4개의 카드 카운터로 시각화됩니다.

```
┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
│  누적 순매출     │ │  정산 예정 금액  │ │ 플랫폼 귀속 매출 │ │  현재 구매 전환율│
│  ₩145,290,000    │ │  ₩72,645,000     │ │  ₩72,645,000     │ │  24.5%           │
│  (PG수수료 등 제외)│ │  (지급 보류 0건)  │ │  (누적 수수료)   │ │  [구간 2 - 35%형]│
└──────────────────┘ └──────────────────┘ └──────────────────┘ └──────────────────┘
```

* **시각 효과:** 
  - 수치 증가 시 카운터 업(Counter Up) 애니메이션이 적용되어 세션 진입 시 동적인 활력 부여.
  - 현재 구매 전환율 아래에는 현재 적용 중인 성과 연동 RS 모델(Model C)의 달성 구간을 보라색 배지 형태로 출력.

---

### 3-2. 월별 매출 및 RS 배분 차트 (Stacked Bar Chart)
정산 데이터를 월별 누적으로 추이를 파악할 수 있도록 좌측에는 매출 누적 차트, 우측에는 결제 수단별/굿즈별 비중을 표시하는 도넛 차트를 배치합니다.

* **스택 바 차트 (Stacked Bar Chart):**
  - X축: 정산 월 (최근 6개월)
  - Y축: 금액 (원화)
  - 스택 요소: `파트너 정산 분배금 (Indigo)` + `AFTERGLOW 수수료 분배금 (Emerald)`
  - Hover Interaction: 차트 바에 마우스를 올릴 때 툴팁을 통해 정확한 금액 비율 및 PG 공제 원장 세부 노출.

---

### 3-3. 세부 정산 테이블 명세 (Settlement Table Grid)
정산 명세를 행별로 조회하고 상태를 변경할 수 있는 데이터 그리드입니다.

| 컬럼명 | 타입 | 가로폭 | 스타일 / 정렬 | 설명 |
| --- | --- | --- | --- | --- |
| **정산 월** | `String` | 10% | Left / Regular | 예: `2026-06` |
| **총 결제액** | `Number` | 15% | Right / Bold | 화폐 포맷 (예: `₩35,000,000`) |
| **공제 수수료** | `Number` | 10% | Right / Regular | PG 수수료 3.3% 기준 등 (예: `₩1,155,000`) |
| **순매출** | `Number` | 15% | Right / Bold | 총 결제액 - 공제 수수료 |
| **적용 RS 모델** | `String` | 15% | Center | `Model A` (Standard), `Model B`, `Model C` |
| **정산 비율** | `String` | 10% | Center | 예: `50%` (또는 `Partner 35%`) |
| **파트너 정산금** | `Number` | 15% | Right / Extra-Bold | 최종 배분 지급액 |
| **정산 상태** | `Badge` | 10% | Center | 정산 대기 / 정산 확정 / 지급 완료 상태 배지 |

* **정산 상태 배지 컬러 코드 (Status Badges):**
  - `정산 대기` (Pending): `#F59E0B` (Yellow) 배경 / `#FFFFFF` 텍스트
  - `정산 확정` (Confirmed): `#3B82F6` (Blue) 배경 / `#FFFFFF` 텍스트
  - `지급 완료` (Settled): `#10B981` (Green) 배경 / `#FFFFFF` 텍스트

* **인터랙션 명세:**
  - **Row Double-Click:** 테이블의 특정 행을 더블클릭할 시, 해당 월의 일별 매출 세부 내역 및 결제 취소 건 상세 리스트가 우측 슬라이드-인 모달(Drawer)을 통해 나타납니다.
  - **Action Button Area:** 
    - [엑셀 다운로드 (XLSX)] 버튼 (그리드 우측 상단 배치)
    - [지급 승인] 버튼 (관리자 및 슈퍼 어드민만 활성화되는 권한별 동작 버튼)
