# 어드민 디자인 교체 작업 가이드

> 작성: 2026.07.04  
> 목적: 에이전트(Antigravity, Claude Code 등)에게 어드민 디자인 교체를 맡길 때 사용하는 가이드  
> 위치: `afterglow-admin` 레포 전용

---

## 현재 어드민 상태

| 항목 | 현황 |
|---|---|
| 스타일 방식 | **인라인 `style={{}}`로 색상 하드코딩** — CSS 파일 없음 |
| 기존 색상 | 다크 배경 `#0D0D0F`, 골드 `#C9A84C`, 배경 `#F7F5F0` |
| 페이지 파일 | `Dashboard.jsx`, `ConceptBot.jsx`, `Monitor.jsx`, `Report.jsx`, `IPUpload.jsx`, `Settlement.jsx` (각 ~28KB) |
| 폰트 | DM Sans + Playfair Display (인라인 지정, CDN 미사용) |

---

## 새 디자인 방향

어드민은 운영자 업무 도구 → **기능 우선, 심플 화이트/블랙**

| 요소 | 기존 | 변경 후 |
|---|---|---|
| 배경 | 크림 `#F7F5F0` | 흰색 `#FFFFFF` / `#FAFAFA` |
| 사이드바 | 블랙 `#0D0D0F` | 딥 그레이 `#111111` (유지) |
| 포인트 컬러 | 골드 `#C9A84C` | **블랙** `#111111` (단색) |
| 보조 색상 | 多 | 그레이 스케일 + 상태별 색 최소화 |
| 폰트 | DM Sans | DM Sans (유지) |

> **어드민 ↔ 유저뷰 디자인 독립**: 어드민은 화이트/블랙, 유저뷰는 오프화이트+버건디. 두 앱은 디자인 방향이 완전히 다르다.  
> **공유 항목**: 감정 축 색상(SSOT 팔레트) — 아래 주의사항 참고.

## 작업 순서 (페이지별 색상 교체)

`src/index.css` 와 `main.jsx` import는 이미 완료되어 있습니다.  
남은 작업: 각 페이지 파일의 인라인 색상을 CSS 변수로 교체.

### 색상 교체 매핑표

| 기존 하드코딩 | 교체 값 | 비고 |
|---|---|---|
| `"#F7F5F0"` | `"var(--bg)"` | 메인 배경 |
| `"#FFFFFF"` | `"var(--surface)"` | 카드·팝업 배경 |
| `"#0D0D0F"` (사이드바) | `"var(--sidebar-bg)"` | |
| `"#C9A84C"` (골드) | `"var(--accent)"` | 포인트 색 |
| `rgba(201,168,76,...)` | `"var(--accent-dim)"` 또는 `"var(--accent-mid)"` | 투명도에 따라 |
| `rgba(255,255,255,0.06)` (사이드바 테두리) | `"var(--sidebar-border)"` | |
| `rgba(255,255,255,0.7)` (사이드바 텍스트) | `"var(--sidebar-text)"` | |
| `"#4CAF7C"` (성공/그린 — UI 상태) | `"var(--color-success)"` | **감정 축 그린은 제외** |
| `"#E87B7B"` (위험/레드) | `"var(--color-danger)"` | |

### 에이전트 지시 프롬프트 (파일 1개씩 복붙)

```
afterglow-admin/src/pages/operator/[파일명].jsx 파일만 수정해줘.
인라인 style={{}} 안의 색상 하드코딩을 아래 매핑에 따라 CSS 변수로 교체해.

[위 매핑표 붙여넣기]

규칙:
1. 레이아웃(flex, grid, padding, margin, width, height, borderRadius)은 절대 건드리지 마
2. 색상 값만 교체할 것
3. 기능 코드(이벤트 핸들러, 데이터, 상태관리) 수정 금지
4. 아래 감정 축 색상은 SSOT 팔레트이므로 절대 변경 금지:
   #7B9EE8, #9A7EE8, #6B8EAE, #E8A84C, #4CAF7C(감정축), #E87B7B(감정축), #9A9490, #C9A84C(감정축)
5. 이 파일 하나만 수정하고 끝낼 것
```

## 주의사항

> [!IMPORTANT]
> **에이전트 지시 시 반드시 명시**
> - "레이아웃 구조는 건드리지 말 것"
> - "한 번에 한 파일씩만 수정"
> - "기능 코드 수정 금지"

> [!WARNING]
> **이 색상들은 SSOT 팔레트 — 절대 변경 금지**  
> `#7B9EE8` `#9A7EE8` `#6B8EAE` `#E8A84C` `#4CAF7C` `#E87B7B` `#9A9490` `#C9A84C`  
> Monitor·Report 페이지의 **감정 축 색상**. 유저뷰 SSOT와 공유됨. 건드리면 두 앱 모두 색상 불일치 발생.

## 각 파일 수정 후 검증

```bash
cd afterglow-admin && npm run dev
```

파일 1개 수정할 때마다 확인:
- [ ] 빌드 에러 없음
- [ ] 해당 페이지 색상 정상 표시
- [ ] 사이드바 네비게이션 동작
- [ ] 레이아웃 깨짐 없음
